## 📚 University Projects

  - **Project:** [Compiler Development](https://github.com/Iyansr97/DLP_2025_Compiler.git)
    – Compiler built from scratch for the Programming Language Design course. It implements every phase of compilation: lexical and syntactic analysis from ANTLR grammars, construction of the abstract syntax tree, semantic analysis with type checking, and code generation for the MAPL virtual machine, where the compiled programs are executed. Several language extensions were later developed in independent branches.

It follows a microservices architecture: a gateway routes requests to independent services for users, authentication, questions, game history, Wikidata and the LLM, with a React frontend.   - **Project:** [Secure E-commerce Infrastructure on OpenStack](https://github.com/CodeSFI/ASSW_Lab_Project) *([CodeSFI](https://github.com/CodeSFI))*
    – Automated deployment and configuration of a secure e-commerce infrastructure on OpenStack, designed with defence in depth. Terraform provisions five virtual machines across isolated networks (DMZ, application, data and management), and Ansible configures them with reusable roles and secrets protected with Ansible Vault. All administration goes through a single bastion host, the only public web entry point is an Nginx load balancer with a ModSecurity/OWASP CRS web application firewall, TLS, HSTS and rate limiting, and the PostgreSQL database sits in a network without internet access. A script verifies the security of the perimeter.
